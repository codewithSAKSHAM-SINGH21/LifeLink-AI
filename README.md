# 🌍 Overview

LifeLink AI is a **full-stack AI-powered emergency response platform** designed to provide immediate assistance during critical situations.

The platform combines **AI-powered first aid guidance**, **one-click SOS**, **nearby hospitals & police locator**, and **secure user authentication** into one seamless experience.

Whether it's finding emergency services, getting instant first-aid instructions, or accessing personal emergency information, **LifeLink AI helps users when every second matters.**

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/codewithSAKSHAM-SINGH21/LifeLink-AI.git
```

---

## Frontend

```bash
cd client

npm install

npm run dev
```

---

## Backend

```bash
cd server

npm install

npm run dev
```

---

# ⚙️ Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret

GEMINI_API_KEY=your_api_key
```
